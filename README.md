# ubuntu-server-secure

Bash script to automatically harden and secure a fresh Ubuntu server in seconds.

## Features
- 🚀 Fast and optimized
- 🔒 Secure by default
- 🛠 Easy to configure

## Installation
```bash
git clone https://github.com/HafezMosleh/ubuntu-server-secure.git
cd ubuntu-server-secure
```
